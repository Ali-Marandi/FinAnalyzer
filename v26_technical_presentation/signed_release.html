Release امضاشده بدون private key در CI
کلید امضا در repository، PFX، command line یا GitHub runner نگهداری نمی‌شود.
01 / REF

Release Tag

تنها tag semantic و commit منطبق با tag برای build پذیرفته می‌شوند.

02 / BUILD

Windows Runner

build، dependency gate و test suite در runner میزبانی‌شده اجرا می‌شوند.

03 / IDENTITY

GitHub OIDC

JWT کوتاه‌عمر با Microsoft Entra برای token محدود مبادله می‌شود.

04 / SIGN

Artifact Signing

Azure، Authenticode با SHA-256 و RFC 3161 timestamp را اعمال می‌کند.

05 / VERIFY

Evidence Release

EXE، SHA-256 و signer/timestamp evidence برای verifier مستقل منتشر می‌شوند.

Environment Approval`production-signing` به reviewer مستقل و منع self-review وابسته است.
Immutable ActionsActionهای workflow روی SHA ثابت pin شده‌اند تا tag متحرک supply-chain نشود.
Timestamp Verify`signtool verify /tw` و Authenticode status، signature و RFC 3161 را کنترل می‌کنند.
Fail Closedنبود OIDC config، signature یا timestamp مانع انتشار artifact قابل اعتماد است.
پیش‌نیاز عملیاتی: Azure Artifact Signing، Federated Credential و GitHub Environment باید پیش از اولین release واقعی پیکربندی شوند.
Tag → Build → OIDC → Sign → Verify
